BCAR

Handover pack

Construction ancillary for installation to issued details. Photo log, seal register and product evidence for the Assigned Certifier. Not a design certificate.

Install-only does not mean an absence of paperwork. It means we do not issue a design certificate. The Assigned Certifier still requires evidence that the installation matches the issued details.

Photo log

Before, during and after. Referenced to seal IDs so the pack can be read against the register.

Seal register

ID, location, system, date, installer. Used by the O&M file and the Assigned Certifier.

Product file

Data sheets, Declarations of Performance, and fire test / ETA evidence for the systems installed.

Install ancillary

Construction ancillary certificate: installation to issued details only. CIF-style Cs / Css family — wording confirmed with the Assigned Certifier on each project. Not a design ancillary.
