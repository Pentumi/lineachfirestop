Services

What we install

Fire stopping contractors Ireland: labour and certified materials to the details on your drawings. Passive fire protection install — not design.

Openings

Penetration sealing

Pipes, cables, cable trays and ducts through compartment walls and floors. We install the tested system named on the issued specification.

Typical package: after M&E first-fix, reinstate the compartmentation at service openings. That is the usual firestop install Dublin and Leinster main contractors buy.

We work from penetration schedules and details. If an opening is not on the schedule, it is a variation or a provisional sum — not a hunt through the riser.

  • Service penetrations as drawn
  • Mixed services only where the issued system covers them
  • Tags / IDs to match the seal register

Need this in a county?

Penetration sealing is the core of most M&E packages we quote.

Dublin · Meath · Kildare · Wicklow

Linear

Joints

Linear gap seals and movement joints where the drawings show a fire-resisting joint system. Head-of-wall, floor-to-wall, and construction joints as detailed.

We do not invent a joint detail on site. If the spec is silent, the question goes back to the design party. Then we install what they issue.

Voids

Cavity barriers

Cavity barriers and void barriers where they appear on the issued details — masonry cavities, rainscreen, and compartment line closers as specified.

Same rule as penetrations: we install the system on the drawing. We do not survey a facade to decide where barriers should have been.

Systems

Tested systems

We install manufacturer-tested firestop systems that your specification names. Common families on Irish commercial jobs include Hilti, Rockwool Firepro, Promat and Nullifire — we use what the issued spec requires, not a house brand.

We do not pick the system for you. System selection is design. If the spec lists an equivalent, the design party confirms the equivalent. We then buy and install that system and keep the evidence folder.

BCAR

Handover pack

Install-only is not no paperwork. It means no design certificate. The Assigned Certifier still needs evidence that the install matches the details.

Photos

Before, during and after. Tied to seal IDs so the pack can be read against the register.

Seal register

ID, location, system, date, installer. The record the O&M and Assigned Certifier actually use.

Product file

Data sheets, Declarations of Performance, and fire test / ETA evidence for the systems installed.

Install ancillary

Construction ancillary certificate: install to issued details only. CIF-style Cs / Css family — wording confirmed with the Assigned Certifier per job. Not a design ancillary.

TGD B / Part B language. Irish BCAR, not UK forms. Get a quote.
