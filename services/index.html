Services

Installation services

Fire stopping contractors Ireland: labour and certified materials installed to the details on your drawings. Passive fire protection installation — not design.

Openings

Penetration sealing

Pipes, cables, cable trays and ducts through compartment walls and floors. We install the tested system named on the issued specification.

Typical package: after M&E first-fix, reinstatement of compartmentation at service openings. This is the firestop installation package typically purchased by main contractors in Dublin and Leinster.

We work from penetration schedules and details. An opening that is not on the schedule is treated as a variation or a provisional sum — not as a search of the riser for undocumented openings.

  • Service penetrations as drawn
  • Mixed services only where the issued system covers them
  • Tags / IDs to match the seal register

Coverage

Penetration sealing is the core of most M&E packages we quote.

Dublin · Meath · Kildare · Wicklow

Linear

Joints

Linear gap seals and movement joints where the drawings show a fire-resisting joint system. Head-of-wall, floor-to-wall, and construction joints as detailed.

We do not invent a joint detail on site. If the specification is silent, the query is referred to the design party. We then install what they issue.

Voids

Cavity barriers

Cavity barriers and void barriers where they appear on the issued details — masonry cavities, rainscreen, and compartment line closers as specified.

The same rule applies as for penetrations: we install the system shown on the drawing. We do not survey a façade to determine where barriers ought to have been provided.

Systems

Tested systems

We install manufacturer-tested firestop systems named on your specification. Common families on Irish commercial projects include Hilti, Rockwool Firepro, Promat and Nullifire — we use the system the issued specification requires, not a substitute of our choosing.

We do not select the system. System selection is a design duty. If the specification lists an equivalent, the design party confirms that equivalent. We then procure and install that system and retain the evidence file.

BCAR

Handover pack

Install-only does not mean an absence of paperwork. It means we do not issue a design certificate. The Assigned Certifier still requires evidence that the installation matches the issued details.

Photos

Before, during and after. Referenced to seal IDs so the pack can be read against the register.

Seal register

ID, location, system, date, installer. The record used by the O&M file and the Assigned Certifier.

Product file

Data sheets, Declarations of Performance, and fire test / ETA evidence for the systems installed.

Install ancillary

Construction ancillary certificate: installation to issued details only. CIF-style Cs / Css family — wording confirmed with the Assigned Certifier on each project. Not a design ancillary.
